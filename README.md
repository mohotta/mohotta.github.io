# Personal Portfolio - Kumudu Mohottala

### Tech Stack
- nextjs
- typescript
- tailwind css

### To run this project locally
1. Clone the project
```
git clone https://github.com/mohotta/mohotta.github.io.git
```
2. Install Dependencies
```
npm install
```
3. Run in localhost
```
npm run dev
```
4. Access in browser using localhost:\<port number\>
